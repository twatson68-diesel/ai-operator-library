How this is organized

  • Layers follow Nufar Gaspar's Agent OS: Identity → Context → Skills → Memory → Connections → Verification → Automations.
  • Layer 0 is Karpathy's LLM Wiki second brain — raw sources in, wiki pages the model writes.
  • BUILD means the episode walks through building something live. Those sort first.
  • Protocol, infrastructure, enterprise-rollout and company-profile episodes were cut.
  • Refreshed weekly against a written rubric — read or correct the taste profile.
